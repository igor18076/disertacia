# Отчёт по этапам 0 и 1

Проверки выполнены 20 ноября 2026 года в рабочей копии на Windows. Характеристики целевого сервера в техническом задании предоставил заказчик. Фактическую конфигурацию Debian фиксирует вывод `sh scripts/preflight.sh` при развёртывании.

| Проверка | Результат |
|---|---|
| Рабочая машина | Windows 10 x86-64, Git 2.53.0, Python 3.12.6. На диске рабочей копии около 41 GiB свободно. |
| Доступ к контейнерам | Docker Engine отсутствует на Windows и в доступной среде WSL. Проверка в WSL обнаружила отсутствие Docker и вернула код 1. |
| Сборка пакета и зависимости | `uv sync --locked --group test` собрал пакет в изолированном окружении. `uv pip check` прошёл. Для Linux x86-64 проверено разрешение зависимостей из того же lock-файла. |
| Compose | CLI 2.40.3 принял `docker compose --profile test config --quiet`. Проверены публикация порта, внутренние сети, профиль тестов и переопределение лимитов. |
| Миграция | `alembic upgrade head --sql` сформировал транзакцию с созданием схемы `coursegen` и записью ревизии `0001_infrastructure`. |
| API | На Windows процесс Uvicorn ответил HTTP 200 на `/health` и HTTP 503 на `/ready` при недоступных PostgreSQL и Qdrant. |
| Тесты | 9 модульных тестов прошли. Pytest обнаружил все 4 интеграционных теста для полного стека. |
| Подготовка первой установки | В WSL проверены права 0600 у `.env`, конкурентное создание файла, сохранение пароля при повторном запуске и отсутствие пароля в выводе. |
| Сценарий приёмки | В WSL прошли 10 сценариев с подменой Docker-команд и HTTP-транспорта, включая отказы миграции, readiness и pytest. |

Для завершения приёмки на Debian выполните `sh scripts/accept-infra.sh` из клонированной рабочей копии. Скрипт проверяет миграцию, HTTP 200 от `/ready` с доступными PostgreSQL и Qdrant и код завершения контейнера с тестами. Путь к отчёту с Git-коммитом и результатом прогона выводится в терминал.
