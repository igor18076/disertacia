## Первый прогон на Debian

20 ноября 2026 года в 05:21 UTC для коммита `343bd4b` с локальными изменениями прошли шаги `env` и `preflight` (Docker Engine 29.10.0, Compose 5.8.0). На шаге `stack` во время `uv sync` сборщик исчерпал попытки разрешить имя `files.pythonhosted.org` при загрузке `psycopg==3.3.9`. Отчёт завершился с `FAIL stack (1)`. Проверки миграции, готовности API и интеграционные тесты в этом прогоне не выполнялись. [Диагностика сборки](deployment.md#ошибка-dns-при-загрузке-пакетов-python)

21 ноября 2026 года в 01:34 UTC для коммита `aacdae7` с локальными изменениями снова прошли `env` и `preflight`. Compose принял адреса PyPI, полученные на хосте. При попытке скачать `numpy==2.5.5` команда `uv sync` исчерпала попытки установить TCP-соединение с `files.pythonhosted.org`. В этом прогоне также получен `FAIL stack (1)`; проверка сервисов ожидает успешной сборки.

Для следующего запуска подготовлен архив из 42 wheels для Linux amd64, SHA-256 `fdf9a4ff39743de816049193fe17c1bfc51e5c45ede0f899068a11bcada6b19f`. В изолированном Linux-окружении WSL из закреплённых образов зависимости установились без доступа к PyPI. Alembic применил ревизию `0001_infrastructure` к PostgreSQL 17.12. Запущенный API вернул HTTP 200 от `/ready` с обеими проверками `ok`, включая Qdrant 1.20.2. Прошли 9 модульных и 4 интеграционных теста.

Для Compose 5.8.0 и Buildx 0.39.0 проверена итоговая конфигурация всех трёх целей сборки. Критерием приёмки на целевом сервере остаётся `result=PASS` после запуска [с локальными пакетами Python](deployment.md#сборка-с-локальными-пакетами-python).
